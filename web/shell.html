COLOR LINES

Gamos, Moscow, 1992 — Olga Demina, Igor Ivkin, Gennady Denisov. The original game reconstructed from LINES.EXE: the same random balls, the same lines, the same score, to the last rounding of its 6-byte floating point.

The game's pictures

This page contains no part of the original game. It draws with the original's pictures, one file of it: LINES.LIB (200 KB). It can download it for you from the copy at the Internet Archive; it then stays in this browser's storage and is never sent anywhere. Color Lines is still Gamos' work: whether to use that copy is your decision.

Or use your own copy: choose LINES.LIB or the game's zip as it is (or drop it on this page).

How to play

Move a ball to a free cell it can reach (click it, then click where; or the arrow keys and Space). Five or more balls of one colour in a row — across, down or diagonal — vanish and score; otherwise three new balls arrive (the Next three at the top). The faster you think, the more a line is worth (but only after long thoughts does it show). Beat the king's score to take his crown.

F1 help, F2 sound, F3 the next balls shown or not, F4 start again, Esc the title, F11 full screen.

Source code and notes: github.com/rembish/color-lines-game.
